# 기술 설명 — 뉴 룸매니아 또르륵 청춘 (SLPM-65235) 한글패치

참고한 이전 작업: 지옥소녀(한자 슬롯 한글 2,350자·스크립트 재작성·전수 검사), 키타로(폰트 슬롯),
반지원정대(UDF/ISO, 리소스 크기 고정 함정), 테니스의 왕자·나디아(ELF 문자열 재배치, 이미지 재작성).

### 글자 그리기 규칙 (ELF 분석)
- F22 렌더러(0x12d110): 2바이트씩 읽어 SJIS→JIS(0x12cb20) → 인덱스 = 94×(구−1)+(점−1), 범위표(0x33ed90) 2개: 글꼴0 0~1409, 글꼴1 1410~4417. **1바이트 문자 불가**(대화상자 등). `/RRGGBBAA/` 색 태그, `<`,`>` 태그 처리(0x12cc20) → 번역문에 `/ < >` 금지.
- 벡터 렌더러(0x2bd9c0): VFI 선형 탐색, 문자열당 최대 32자, 2바이트 전용.
- 메일/PC 본문에는 원문에 반각 ASCII(URL·이모티콘)가 있음 → 메일 렌더러의 반각 처리 실기 확인 필요.
- 그 외 F22_002/003(2수준 한자)은 게임이 쓰지 않음.

## 2. 인코딩
- 한글 2,350자 → SJIS 1수준 한자 코드(0x889F~ JIS 순) 1:1 (`tools/kmap.py`).
- 가나·전각 기호·영숫자 글리프는 그대로. 번역문에 한자·가나 금지(슬롯이 한글로 덮임).
- 전각만 사용: 띄어쓰기 `　`, 문장부호 `，．！？…～「」（）`. 반각은 실기 확인된 곳(메일 URL 등)만.

## 3. 작업 단계
1. 도구: ISO/CVM 패치(완료), F22 생성(완료), VFS 생성, ADS 추출/재조립, ELF 문자열 추출/주입, EXTEND·SCRDAT 추출/주입, 이미지 추출/재작성, 검사, 빌드.
2. 번역: 기계번역 금지, 직접 번역. `translation/번역_규칙.md`, `translation/glossary.tsv` 준수.
   - 분량: SCNSCR 약 14만 자(메일 7만, 일기 4만, PC 채팅 3만), ELF 약 2.5만 자, EXTEND, 물체 이름.
3. 이미지: 메뉴·버튼·달력·정보 화면 등 글자 이미지 조사 후 재작성(원본 둥근 고딕 느낌 → 나눔스퀘어네오).
4. 빌드·검증: 결과 ISO에서 일본어 잔존 검사, 백그라운드 PCSX2(가상 패드 PINE)로 화면 확인, xdelta(무압축) 생성.
5. 정리: 원본 폴더에 ISO/xdelta/README, 중간 파일 삭제.

## 4. 위험 요소
- 메일 렌더러의 줄 폭·반각 처리 → 실기 측정.
- VFS 크기 증가 시 힙 여유 → 원본 크기(929,444바이트) 이하 목표, 넘으면 윤곽 단순화.
- 스크립트 내 다른 절대 오프셋 존재 가능성 → 재조립 후 동일 길이 왕복 검증 + 실기 확인.

## 5. 추가 기술 메모 (v1.0)
- **소형 글꼴(MOZI) 확장**: 행동 목록 글꼴은 Dreamcast식 트위들 텍스처. 실행 파일 끝(_end 뒤) 코드 동굴에 글자 대응표 후킹(4바이트 표)을 두고 힙 시작을 뒤로 밀었다. 동굴 앞 0x40 바이트는 crt0 bss 초기화가 지우므로 비워 둔다.
- **좁은 띄어쓰기**: 0x81B0 을 빈 글리프로 두고 F22 렌더러(0x12D57C)에서 전진폭을 절반으로.
- **동영상 자막**: Sofdec SFD(MPEG-2 640x448)를 전체 재인코딩한 뒤 `sofdec_remux.py` 로 영상 섹터만 다시 채움(음성 섹터·팩 헤더·파일 크기 원본 유지).
- **방 안 TV 프로그램(ADX/TV/*.TV)**: 1024바이트 팔레트 + 블록당 64x48 픽셀 256색(8픽셀 세로 띠 배치) 영상. 너무 작아 자막을 넣지 않음.
- **같은 그림 복사본**: PC 화면 그림은 장면마다 같은 그림이 따로 들어 있다. `build_img._auto_dup` 이 복호한 픽셀이 같은 텍스처에 같은 명세를 자동 적용.
- **16:9 HUD 보정**: GIF 패킷 전송 함수 0x1A1C30 앞에 끼어들어(빈 메모리 0xF0000 의 코드), PACKED/A+D 의 XYZ2·XYZF2·XYZ3·XYZF3 의 X 를 (X−0x8000)×3/4+0x8000 으로 바꾼다. 3D 는 다른 경로라 영향 없음. 마우스 커서 객체(스프라이트 함수 0x16D650 ← 0x12E160 경로, 깊이 −1.1)는 클릭 위치와 맞도록 제외.
