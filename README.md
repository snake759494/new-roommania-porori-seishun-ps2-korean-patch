## 패치 적용 방법

### Windows 에서 원본 확인

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\New Roommania - Porori Seishun (Japan).iso'
```

위 표와 다르면 적용을 중단하세요. CHD·CSO 로 변환한 이미지에는 적용할 수 없습니다.

### xdelta UI 사용

1. 릴리즈에서 `New_Roommania_Porori_Seishun_KO_v1.0.xdelta` 를 받습니다.
2. xdelta3 패치를 지원하는 도구(xdeltaUI 등)의 **Apply Patch** 기능을 엽니다.
3. **Patch** 에 xdelta 파일, **Source File** 에 해시가 일치하는 원본 `.iso` 를 선택합니다.
4. **Output File** 에 새 파일명(예: `New Roommania - Porori Seishun (Korean).iso`)을 지정합니다.

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s '.\New Roommania - Porori Seishun (Japan).iso' '.$X' '.\New Roommania - Porori Seishun (Korean).iso'
```

## 16:9 와이드 화면 패치 (PCSX2)

`SLPM-65235_4CBE0B5C.pnach` 는 v1.0 한글판용 와이드 패치입니다. 저장소의 `widescreen/` 폴더에도 같은 파일이 있습니다.

- **3D 화면**: PCSX2 공식 패치 모음(pcsx2_patches)의 원본 일본판용 패치(CRC 9EB4AA0B, 작성자 Arapapa)와 같은 내용입니다. 카메라 시야 값(EE `0x005C07DC`, 1.0→0.75)을 바꿔 방이 좌우로 넓게 보입니다.
- **2D 화면(HUD 보정)**: 원본 패치에는 없던 기능입니다. 메뉴·대화창·달력·행동 목록·타이머·점수 화면·만화 같은 2D 그림과 글자가 **가로로 늘어나지 않고 원래 4:3 비율로 화면 가운데에** 나오도록 그래픽 전송 함수(EE `0x001A1C30`)에 보정 코드를 넣었습니다(코드 위치 EE `0x000F0000`, 게임이 쓰지 않는 메모리).
- **마우스 커서**: 커서와 커서에 붙는 물체 이름표는 3D 물체를 가리켜야 하므로 보정하지 않습니다. 커서가 가리키는 곳이 실제 클릭 위치입니다.

> 한글판은 실행 파일이 바뀌어 원본판(CRC **9EB4AA0B**)과 CRC 가 다릅니다(한글판 **4CBE0B5C**). PCSX2 에 기본 내장된 원본판 와이드 패치는 한글판에 자동 적용되지 않으므로, 반드시 이 파일을 사용하세요. 원본판에 이 파일을 쓰거나 한글판에 원본판 패치를 쓰지 마세요.

**적용 방법 (PCSX2 2.x)**
1. `SLPM-65235_4CBE0B5C.pnach` 를 내려받습니다. **파일 이름은 바꾸지 마세요.** (PCSX2 는 `게임ID_CRC.pnach` 이름으로 찾습니다.)
2. PCSX2 의 `patches` 폴더에 넣습니다.
   - 설치판: `문서\PCSX2\patches`
   - 포터블판: PCSX2 실행 파일 옆의 `patches` 폴더
   - 정확한 위치는 PCSX2 **설정 → 폴더**(또는 도구 → 데이터 디렉터리 열기)에서 확인할 수 있습니다.
3. 게임 목록에서 한글판 게임을 **우클릭 → 속성 → 패치** 탭을 엽니다.
4. **Widescreen 16:9** 항목에 체크합니다.
5. 게임을 **새로 부팅**합니다. (세이브스테이트 불러오기로는 적용되지 않을 수 있습니다.)
6. 부팅할 때 "게임 패치가 활성화되었습니다" 알림이 나오고 화면이 16:9 로 바뀌면 적용된 것입니다.

**참고**
- 화면 비율은 패치가 자동으로 16:9 로 바꿉니다(`gsaspectratio=16:9`). 그래픽 설정의 화면 비율은 기본값(자동)으로 두세요. 직접 4:3 이나 늘이기로 정해 두면 2D 화면 비율이 어긋납니다.
- 패치 탭에 항목이 보이지 않으면 게임 속성의 요약 탭에서 CRC 가 **4CBE0B5C** 인지 확인하세요. 다르면 패치 버전이 맞지 않는 것입니다.
- 2D 화면 양옆은 3D 장면이면 3D 가, 2D 전용 화면(타이틀·달력 등)이면 검은 띠가 보입니다(정상).
- 와이드 화면을 끄려면 패치 탭의 체크를 해제하고 다시 부팅하세요.
- 실기(PS2 본체)에서는 쓸 수 없습니다(PCSX2 전용).
